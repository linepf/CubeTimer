# CubeTimer

### “CubeTimer”는 큐브를 돌려 원하는 면을 위로 올리기만 하면 설정된 시간이 즉시 시작되는 직관적인 모션 인지 타이머입니다.
### 기존 타이머의 번거로운 버튼 조작을 없애고 큐브를 뒤집는 모션만으로 시간에 즉시 몰입할 수 있도록 제작했습니다.

### 담당 역할 : STM32f103 펌웨어 개발, 회로 및 PCB 설계, 3D외관설계
### 주요 요약 : 
### - MPU6050 센서 인터럽트 기반 통신(I2C)
### - 전원경로관리회로(동시 충방전 회로) 설계, 
### - Bare-Metal Programming, EXTI 및 NVIC 레지스터 제어
### - FND다중화 제어, ADC측정
### 사용 보드 : 커스텀보드 제작
### 개발 환경 : STM32CubeIDE
